# Gift Message Studio

Telegram-бот + Mini App для макетов сообщений «Вам отправили подарок» (для видео и контента).
**Это макет**: настоящих подарков, переводов и оплат нет. Бот пишет только в личный чат с тем, кто нажал кнопку.
Работает на своём сервере, без Base44 и без платных API.

## Дизайн
Liquid glass: полупрозрачные панели с размытием фона, светлая кромка и внутренний блик, анимированный градиентный фон. Карточка подарка всегда строго по центру экрана (проверено замером: центр блока = центр кадра 540×960, в том числе с датой и длинным именем).

## Что приходит в чат
Бот присылает **видео-карточку** (MP4, H.264, 720×1280, 5 с): карточка «выскакивает» с пружинным эффектом, покачивается, на кнопке мерцают искры, из центра взрывается конфетти. К сообщению добавляется нативный эффект 🎉 (если Telegram его не примет, видео уходит без эффекта) и кнопка «Посмотреть» (показывает «Это макет»). Рендер идёт в отдельном потоке, очередь на 2 одновременных, кэш на 24 часа.

## Свой подарок (полностью офлайн)
Название, номер, модель, фон, узор, два цвета градиента, символ-узор (эмодзи) и саму картинку ты задаёшь сам: вкладка «✨ Свой» в Mini App, либо в чате с ботом: пришли картинку с подписью `Название | номер | модель | фон | узор | отправитель`. Картинка и данные никуда не уходят, кроме твоего бота, и не обращаются к t.me/fragment. Проверено запретом сети в тесте.

## Что умеет
- `/start` — приветствие, кнопка «Открыть пульт» (Mini App).
- `/gift 75 Имя` — макет звёздного подарка.
- `/nft t.me/nft/LoveCandle-123 Имя` — макет NFT-подарка (модель, фон, узор берутся с t.me автоматически).
- Просто пришли боту ссылку `t.me/nft/…` — получишь макет сразу.
- **Mini App (пульт)**: живой макет с конфетти, искрами на кнопке и пружинной анимацией, редактирование всех текстов, цвет карточки, светлый/тёмный фон чата, метка МАКЕТ, кнопка «Показать в чате» и режим **«Для записи»** (полный экран 9:16, тап = повтор, двойной тап = выход). Именно этот режим выглядит как настоящее сообщение Telegram по центру экрана: снимай запись экрана.

## Запуск

1. Создай бота в @BotFather, получи токен.
2. Скопируй `.env.example` в `.env` и заполни:
   ```
   BOT_TOKEN=токен
   WEBAPP_URL=https://твой-домен
   PORT=8080
   ```
   `WEBAPP_URL` должен быть **HTTPS** и вести на этот сервер (порт 8080).
3. Запуск:
   - Docker: `docker compose up -d --build`
   - Без Docker: `pip install -r requirements.txt && python main.py`
4. В @BotFather: `/mybots` → бот → Bot Settings → Menu Button → укажи тот же `WEBAPP_URL` (необязательно, кнопка есть в /start).

### Нет домена? Бесплатный HTTPS
```
cloudflared tunnel --url http://localhost:8080
```
Скопируй выданный `https://….trycloudflare.com` в `WEBAPP_URL` и перезапусти.

### Бесплатный хостинг
Render / Railway / Fly.io: подключи этот репозиторий, команда запуска `python main.py`, переменные `BOT_TOKEN` и `WEBAPP_URL` в настройках.

## 24/7 без вмешательства
- `main.py` держит бота и веб-сервер под супервизором: любой сбой (сеть, Telegram, исключение) → перезапуск через 2, 4, 8… до 60 с.
- Docker: `restart: always` + healthcheck по `/health`.
- Без Docker (systemd): скопируй проект в `/opt/gift-message-studio`, затем
  `sudo cp gift-message-studio.service /etc/systemd/system/ && sudo systemctl enable --now gift-message-studio`
  Логи: `journalctl -u gift-message-studio -f`.
- Данные подарков и картинки кэшируются на диск на 24 часа (`cache/`), поэтому повторные запросы не ходят в сеть и переживают кратковременные сбои.
- Никаких внешних платных сервисов и чужих API: только публичные страницы t.me и nft.fragment.com.
- Цвета фона и узор подарка берутся из самой страницы подарка на t.me (настоящий градиент и иконка узора), а не угадываются.
- Telegram иногда временно режет частые запросы: тогда бот честно пишет «подожди минуту», пустых карточек не рисует.

## Безопасность
- Токен только в `.env` / переменных окружения, в репозиторий не попадает.
- Подпись `initData` проверяется (HMAC), результат уходит только тому `user_id`, кто нажал кнопку.
- Лимит: 3 макета в минуту на пользователя. Данные пользователей не сохраняются.

## Честное ограничение
Telegram не позволяет ботам создавать настоящие служебные сообщения о подарках. Картинка от бота приходит как обычное фото бота. Для видео «как настоящее» используй режим «Для записи» в Mini App.

## Структура
```
main.py        запуск бота и сервера
bot.py         команды бота (aiogram 3)
server.py      FastAPI: Mini App, API, проверка initData
render.py      рисование карточек (Pillow)
gifts.py       парсинг t.me/nft, список коллекций, цвета фонов
webapp/        Mini App (index.html)
```
